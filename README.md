# 武器装备情报查询系统

一个基于 Vue 3 的纯前端武器装备情报查询系统，支持模糊搜索，卡片式展示武器详情与图片。

**无需安装任何环境，直接访问即可使用。**

👉 **在线访问：[https://guanlongbin.github.io/weapon-system/](https://guanlongbin.github.io/weapon-system/)**

---

## 项目结构

```
weapon-system/
├── index.html              # Vue 3 前端（纯静态，含搜索逻辑）
├── missiles.json           # 武器数据（21条）
├── static/
│   └── vue.global.prod.js  # Vue 3 本地文件（离线可用）
├── images/                 # 武器装备图片
├── app.py                  # 本地运行备用（Flask，需 pip install flask）
└── templates/
    └── index.html          # Flask 模板备用
```

---

## 功能特性

- **模糊搜索**：基于 Levenshtein 编辑距离算法，支持拼写相近、部分匹配，不需要输入完整名称
- **加权排序**：武器名称命中权重最高，国家次之，其余字段依次递减
- **对话历史**：左侧记录每次查询，可点击回顾历史结果
- **卡片展示**：图片、类型标签、国家标签、详细参数一览无余
- **内容折叠**：简介支持展开/收起
- **完全离线**：Vue 3 本地化，无需联网，无需 Node.js / npm / Python

## 数据说明

`missiles.json` 包含两类装备共 **21 条**记录：

| 字段 | 说明 |
|------|------|
| `type` | 类型：`导弹` 或 `防御系统` |
| `参战国家` | 美国 / 以色列 / 伊朗 |
| `武器类别` | 武器名称及型号 |
| `典型照片` | 图片相对路径 |
| `简介` | 武器背景与演进历史 |
| `核心性能` | 射程、重量、成本等参数 |
| `制导方式` | 制导技术详情 |
| `本次战争使用情况及战果` | 2026年实战使用记录 |

## 模糊匹配算法

搜索采用 **Levenshtein 编辑距离 + 精确包含** 双重匹配：

1. **精确包含**：关键词直接出现在字段中，得分最高（×10）
2. **编辑距离**：在文本中滑动窗口，找出与关键词最相似的子串，允许最多 `floor(len/3)` 个字符的差异
3. **加权字段**：
   - 武器类别命中：×3
   - 参战国家命中：×2
   - 其余字段：×1
4. 按总分降序返回前 10 条

**示例**：输入 `战锤`（"战斧"的近似写法）也能匹配到战斧巡航导弹。

## 本地运行（可选）

如果需要在**无网络环境**的服务器上运行（而非使用 GitHub Pages），提供了 Flask 备用方案：

```bash
pip install flask
python app.py
# 浏览器访问 http://localhost:5000
```
