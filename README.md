# 武器装备情报查询系统

一个基于 Python + Vue 3 的武器装备情报查询系统，支持模糊搜索，卡片式展示武器详情与图片。**完全离线可用，无需任何前端构建工具。**

---

## 项目结构

```
weapon-intelligence-system/
├── app.py                  # Python/Flask 后端
├── missiles.json           # 武器数据（21条）
├── templates/
│   └── index.html          # Vue 3 前端页面
├── static/
│   └── vue.global.prod.js  # Vue 3 本地文件（离线可用）
└── images/                 # 武器装备图片
```

---

## 功能特性

- **模糊搜索**：后端对武器名称、参战国家、简介、核心性能、制导方式、实战情况等字段进行加权匹配
- **对话历史**：左侧记录每次查询，可点击回顾历史结果
- **卡片展示**：每条结果以卡片形式展示，包含武器图片、类型标签、国家标签、详细信息
- **内容折叠**：简介支持展开/收起，避免页面过长
- **完全离线**：Vue 3 本地化，无需联网，无需 Node.js/npm

## 数据说明

`missiles.json` 包含两类装备共 21 条记录，每条字段如下：

| 字段 | 说明 |
|------|------|
| `type` | 类型：`导弹` 或 `防御系统` |
| `参战国家` | 美国 / 以色列 / 伊朗 |
| `武器类别` | 武器名称及型号 |
| `典型照片` | 图片相对路径（`images/xxx.jpg`） |
| `简介` | 武器背景与演进历史 |
| `核心性能` | 射程、重量、成本等参数 |
| `制导方式` | 制导技术详情 |
| `本次战争使用情况及战果` | 2026年实战使用记录 |

## 快速启动

### 环境要求

- Python 3.8+
- Flask

### 安装依赖

```bash
pip install flask
```

### 启动服务

```bash
python app.py
```

浏览器访问：**http://localhost:5000**

## 后端接口

### `GET /`
返回前端页面。

### `POST /search`

模糊搜索接口。

**请求体：**
```json
{
  "query": "美国 巡航导弹"
}
```

**响应：**
```json
[
  {
    "type": "导弹",
    "参战国家": "美国",
    "武器类别": "对地巡航导弹战斧TLAM（BGM-109）",
    "典型照片": "images/missile_2_美国_对地巡航导弹战斧TL.jpeg",
    "简介": "...",
    "核心性能": "...",
    "制导方式": "...",
    "本次战争使用情况及战果": "..."
  }
]
```

**匹配规则：**
- 关键词命中武器类别：+5 分
- 关键词命中参战国家：+3 分
- 关键词命中其他字段：+出现次数
- 返回得分最高的前 10 条

### `GET /images/<filename>`
返回武器图片文件。

### `GET /static/<filename>`
返回前端静态资源（Vue.js 等）。
