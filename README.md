# 武器装备情报查询系统

基于 Vue 3 的纯前端武器装备情报查询系统，支持模糊搜索，卡片式展示武器详情与图片。

**无需安装任何环境，打开即用。**

👉 **在线访问：[https://guanlongbin.github.io/weapon-system/](https://guanlongbin.github.io/weapon-system/)**

---

## 功能特性

- **模糊搜索**：基于 Levenshtein 编辑距离算法，输入近似词也能匹配
- **快捷入口**：首页提供常用关键词一键查询
- **加权排序**：武器名称命中权重最高，国家次之
- **对话历史**：左侧记录每次查询，可随时回顾
- **卡片展示**：图片、类型、国家、详细参数清晰呈现
- **完全离线**：Vue 3 本地化，部署后无需任何外网依赖

## 数据说明

`missiles.json` 包含两类装备共 **21 条**记录：

| 字段 | 说明 |
|------|------|
| `type` | 类型：`导弹` 或 `防御系统` |
| `参战国家` | 美国 / 以色列 / 伊朗 |
| `武器类别` | 武器名称及型号 |
| `典型照片` | 图片相对路径 |
| `简介` | 武器背景与演进历史 |
| `核心性能` | 射程、重量、成本等参数 |
| `制导方式` | 制导技术详情 |
| `本次战争使用情况及战果` | 2026年实战使用记录 |

---

## 模糊匹配算法

1. **精确包含**：关键词直接出现在字段中，得分最高（×10）
2. **编辑距离**：滑动窗口扫描文本，允许最多 `floor(len/3)` 个字符差异
3. **加权字段**：武器类别 ×3、参战国家 ×2、其余字段 ×1
4. 按总分降序返回前 10 条

## 部署（零配置）

### 方式一：GitHub Pages（推荐，完全免费）

1. Fork 本仓库到你的 GitHub 账号
2. 进入仓库 **Settings → Pages**
3. Source 选择 `Deploy from a branch` → `main` 分支 → `/(root)`
4. 点击 Save，等待 1 分钟
5. 访问 `https://你的用户名.github.io/weapon-system/`

### 方式二：Vercel（推荐，自动部署）

1. 登录 [vercel.com](https://vercel.com)，点击 **Add New Project**
2. 导入 GitHub 仓库
3. 无需任何配置，直接点击 Deploy
4. 自动获得 `https://项目名.vercel.app` 域名

### 方式三：Netlify（拖拽部署）

1. 下载本仓库为 ZIP 并解压
2. 登录 [netlify.com](https://netlify.com)
3. 拖拽文件夹到 Deploy 区域，即刻上线

### 方式四：任意服务器

直接上传所有文件到服务器任意目录，无需安装任何环境，通过浏览器访问 `index.html` 即可。
